## 2. 第一批：SYNC01 身份基础

sol 先实现独立账户存储/服务和无 UI 的身份客户端，使用同一个服务端账户及角色表，不创建平行身份系统。

- 账户默认角色由服务器保存。新端先读取已有角色，不用默认模板回写昵称/外观。
- Bootstrap 只返回本人账户、公开角色投影、默认角色和实际支持的能力，不返回角色私有人设、旧角色 key 或登录凭据。
- 首次创建中性角色与显式选择默认角色需原子化、校验归属并可安全重试；没有角色时客户端不得伪称已完成角色恢复。
- 客户端按服务来源和账号隔离状态；切换账户/退出后取消请求或丢弃旧请求结果，旧结果不能污染新账户。
- 设备 ID 仅为展示/审计标识，不替代令牌认证。完整设备会话管理若尚未接入旧认证生命周期，必须单列未完成。
- 复用原数据库连接与事务。新建账户迁移模块通过依赖注入集成，不另开同文件数据库连接。

接口沿用 14 的 `accountBootstrap`，首次创建/默认选择可增加明确的账户接口。最终名称、参数、错误和返回样例由 sol 写入 16，主负责人审核后作为 Opus 的接入依据。独立模块通过测试不等于三端已接通，SYNC01 在真实接入验收前不能标为完成。
