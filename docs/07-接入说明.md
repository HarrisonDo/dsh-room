# 接入说明

房间有四种接入方式。从上到下，耦合依次变深。

| 方式 | 适合 | 入口 |
|---|---|---|
| 嵌入网页 | 网页、iframe、其他桌面壳 | `dsh-room/web/` 静态文件 |
| 页面命令 | 让外部程序驱动房间 | `room.command()` / `postMessage` |
| 内容包 | 加家具、场景、剧情，不改引擎 | `docs/04-内容格式规范.md` |
| DSH 插件 | 接工作状态、聊天和 Agent 工具 | `dsh-room/` |

## 嵌入网页

`dsh-room/web/` 是纯静态目录，零依赖，已带构建产物。放到任意静态服务下，或直接双击 `index.html`。

```html
<iframe src="/room/index.html?dock=1&w=620" title="大肥鱼的房间"></iframe>
```

| URL 参数 | 作用 |
|---|---|
| `mode=edit` | 直接进布置模式 |
| `scene=living` | 使用指定场景模板 |
| `fresh=1` | 不读存档 |
| `dock=1&w=620` | 右下角挂件 |
| `ui=compact` | 窄屏界面 |
| `transparent=1` | 透明背景 |
| `desk=1` | 桌面模式，由 `desktop/` 使用 |
| `bridge=any` | 接受任意来源的 `postMessage`，默认只收同源 |

只有在信任父页面时才使用 `bridge=any`。

## 页面命令

同页脚本调用 `room.command()`：

```js
room.command({ op: 'agent.say', id: 'whale', text: '在呢~' });
room.command({ op: 'agent.status', id: 'whale', status: 'working', task: '写代码' });
room.command({ op: 'env.set', period: 'night', weather: 'rain' });
room.on('*', (data, ev) => console.log(ev, data));
```

iframe 的父页面用 `postMessage`。带 `reqId` 时会收到结果：

```js
frame.contentWindow.postMessage({ roomkit: { op: 'room.list' }, reqId: 'r1' }, origin);

addEventListener('message', (e) => {
  if (e.origin !== origin) return;
  if (e.data.roomkitReply === 'r1') console.log(e.data.result);
  if (e.data.roomkitEvent) console.log(e.data.roomkitEvent, e.data.data);
});
```

可用命令：

| 分组 | `op` |
|---|---|
| 角色 | `agent.add` `agent.upsert` `agent.remove` `agent.list` `agent.say` `agent.chat` `agent.emote` `agent.pose` `agent.goto` `agent.use` `agent.status` |
| 家具 | `object.add` `object.set` `object.state` `object.remove` `object.list` |
| 房间 | `room.list` `room.go` `room.describe` `scene.get` `scene.load` `env.set` `camera.fit` |
| 演出 | `play.run` `story.list` `story.run` `story.skip` `story.reset` |
| 界面 | `ui.open` `ui.close` `ui.toast` |

常见参数见 `dsh-room/web/README.md`。

事件：`ready` `load` `change` `mode` `object:click` `agent:click` `agent:say` `agent:chat` `agent:status` `scene:change` `scene:open` `play:start` `play:end` `story:start` `story:choice` `story:end` `ui:page` `pack:installed` `packs:loaded`。

## 内容包

新增家具、场景和小剧场只需改数据。示例见 `dsh-room/web/README.md`，完整字段见 `docs/04-内容格式规范.md`。

## DSH 插件

```sh
dsh plugin --profile web add ./dsh-room
```

桌面端要先退出 DSH，再用应用自带的 dsh 命令安装到 `desktop` profile，然后重新打开。修改源码后运行 `npm run build`，再重新加载插件。

插件契约见 `docs/01-DSH插件契约备忘录.md`。

### 路由

| 路径 | 方法 | 作用 | 访问控制 |
|---|---|---|---|
| `/plugins/dsh-room/web/` | GET | 静态页面 | 宿主 Web 服务 |
| `/plugins/dsh-room/api/store` | GET、PUT | 读写存档，键必须以 `dsh-room.` 开头 | 仅本机 |
| `/plugins/dsh-room/api/info` | GET | 返回本机预览地址，不含凭据 | 仅本机 |
| `/api/dsh-room.status` | POST | 工作状态、聊天和工具状态，并领取待执行命令 | DSH 连接鉴权 |
| `/api/dsh-room.chat` | POST | 与角色聊天 | DSH 连接鉴权 |
| `/api/dsh-room.tools` | POST | 开关 Agent 工具 | DSH 连接鉴权 |

### 工作状态

插件监听 `session/event`，只读取事件类型和 todo 文案，不读取会话内容，也不调用模型。状态档位为 `thinking` `working` `result` `waiting` `success` `error`，`null` 表示空闲。

### 聊天

页面传来的人设和房间信息都按不可信输入处理：截断，并只取已知字段。回复使用当前的默认模型，会产生相应的模型调用。

### Agent 工具

`room_look`、`room_say`、`room_do` 默认关闭，需要在页面「社区」中打开。工具只把命令放入队列，由打开的房间页面领取执行；页面约 6 秒没有来取状态时，视为房间未打开。

## 存档

| 运行方式 | 存档位置 |
|---|---|
| DSH 小窗、侧栏、全屏 | `dsh-room` 命名空间，宿主路由可用时同步 |
| 独立网页 | 浏览器 `localStorage` |
| 桌面版 | Electron 用户数据目录 |

这三处互不相通。

## 桌面壳

见 `desktop/README.md`。外壳通过自定义协议读取 `dsh-room/web`，不监听网络端口。
