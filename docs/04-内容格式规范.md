# 04 · 内容格式规范（给创作者：家具包 / 场景 / 剧情 / 角色卡）

> 2026-11-07 补充：本文描述已有本地内容格式；下方场景示例为 v1，当前 `scene.js` 会归一化到 v2。计划中的联网世界包 `roomkit.world`、发布版本和素材依赖见 [11 首版契约](11-AI世界首版契约.md)，尚未实现。单独导出场景 JSON 不等于已经包含访客所需的全部自定义素材。

> RoomKit 的一切内容都是 **纯 JSON**：没有代码、没有 HTML，导入时逐字段校验。
> 做好的内容导出成一个文件就能分享；别人在「🛠 布置 → 素材 → 导入内容包」装上即用。
> 引擎侧实现：`web/roomkit/packs.js`（校验/命名空间）、`catalog.js`（家具）、`scene.js`（场景）、`story.js`（剧情）、`character.js`（角色卡）。

---

## 0. 最快上手：在应用里做，不用写 JSON

1. 「🛠 布置 → 素材 → ＋ 自制家具」：上传一张**透明背景的等距图**（PNG/WebP），选占地格数，拖「大小/左右/上下」滑块，让它和旁边的小鲸鱼比例合适、底边落在绿色占地菱形上 → 「保存并摆放」。
2. 摆好的家具在「我的家具包」里；「导出我的包」得到 `xxx.roomkit.json`，发给别人即可。
3. 场景：「场景 → 导出场景」得到场景 JSON（可带剧情），别人「导入场景」即可玩。

## 1. 内容包 `roomkit.pack`

```jsonc
{
  "format": "roomkit.pack", "v": 1,
  "id": "alice-cafe",              // 字母数字/_/-，≤48；导入后包内所有 id 变成 "alice-cafe/原id"
  "name": "咖啡店家具", "author": "alice", "version": "1.0.0", "license": "CC BY 4.0",
  "description": "吧台、咖啡机、高脚凳",
  "images": { "counter": "data:image/webp;base64,..." },   // 内嵌图片，家具用 "@counter" 引用
  "furniture": [ /* FurnitureDef */ ],
  "scenes":    [ /* Scene（可当模板） */ ],
  "stories":   [ /* Story */ ],
  "plays":     [ /* 小剧场 */ ],
  "characters":[ /* 角色卡 */ ]
}
```

限制（超出拒绝导入）：单图 ≤ 2.5MB、图片总量 ≤ 15MB、家具 ≤ 300、单件零件 ≤ 200、场景 ≤ 20、剧情 ≤ 60。
安全：只认白名单字段；图片只收内嵌 data URL（不允许外链，防追踪）；信息抽屉不收 `html`；动作只收 `toggle:键 / use[:交互位] / play:剧场 / weather / shake / info`。

## 2. 家具 FurnitureDef

| 字段 | 说明 |
|---|---|
| `id` `name` `sub` `cat` `tags` | 身份；`name/sub` 是悬停名牌；`cat`：bedroom living study kitchen deco light rug wall plant fun misc |
| `mount` | `floor` 落地（占格、挡路）· `flat` 地毯（贴地、不挡路、永远在最底层）· `wall` 挂墙 |
| `size: [宽, 深]` | 占地格数（1–8），rot=0 时的朝向：**正面朝屏幕左下（+y），背靠右墙** |
| `height` | 高度（像素，1 格宽 ≈ 128 像素，小鲸鱼约 65 像素高） |
| `blocks` | `false` = 不挡路（门垫之类） |
| `wsize: [宽(格), 高(像素)]` `wz` | 墙饰尺寸与默认离地高度 |
| `art` | 外观，见下 |
| `palette` / `variants` | 调色板（键 → #色值）；`variants` 是几套可一键切换的配色（布置模式 🎨） |
| `slots` | 交互位（角色能在这儿做什么），见下 |
| `states` | 状态，如 `{ "on": false }` |
| `act` | 点击动作：`toggle:on` 开关 · `use:sit` 让角色来用 · `play:剧场id` · `weather` 换天气 · `shake` 晃一晃 · `info` 信息抽屉 |
| `say` | 点击时的浮字（toggle 时 `[开, 关]`） |
| `light` | `{ at:[x,y], z, radius, color, when:"on" }` 光源：夜里在暗处挖出暖色光斑 |
| `info` | `{ title, sub, lines:[[键,值]|文字] }` 信息抽屉内容 |

### 2.1 外观 `art`

**贴图**（最常用，适合 AI 出图）：
```json
{ "kind": "sprite", "src": "@counter", "fit": 1.0, "dx": 0, "dy": 0, "sy": 1, "parts": [ ... ] }
```
- 贴图宽度 = 占地在屏幕上的宽度 × `fit`；底边对齐占地的最前角（地毯：中心对齐）。
- `dx/dy`：像素微调；`sy`：纵向压扁（俯视画法的地毯压成 2:1，常用 0.6）。
- 单视角贴图只有两个朝向（转 90° = 水平镜像）。
- `parts`（可选）：程序化备选零件——贴图加载失败时画它，房间永远不缺家具。

**程序化零件**（四朝向、可换色）：`{ "kind": "proc", "parts": [ ... ] }`，零件坐标是 rot=0 的局部坐标（x/y/w/d/r 单位为格，z/h 单位为像素）：

| 零件 | 字段 |
|---|---|
| `box` 立方块 | `x y z w d h c`，`faces:{top,px,nx,py,ny}` 单面换色，`glow:"py"`+`lit:"on"` 某面发光（屏幕），`o` 不透明度 |
| `cyl` 圆柱 | `x y z r h c`，`open` 顶面画成开口 |
| `cone` 圆台 | `x y z r0 r1 h c`，灯罩：`lit:"on"` 开灯时发光 |
| `ball` 团 | `x y z r c sq`（sq = 竖向扁度）——叶丛、靠垫、豆袋 |
| `rug` 地毯 | `x y w d c b shape:"rect"|"round" pattern:"stripes"|"rings"` |
| `fx` 小动画 | `fx:"fish"`（鱼缸里的鱼） |

`c` 可以是 `#色值` 或调色板键名；`when:"on"/"!on"` 按状态显示零件；`bias` 微调同一家具内零件的前后。
光照约定：顶面最亮、左下面原色、右下面压暗（引擎自动算）。

**墙饰**：`{ "kind": "wall", "draw": "window|door|frame|clock|shelf|poster|image", "src": "@图" }`（`image` 直接贴图）。

### 2.2 交互位 `slots`

```json
{ "id": "sit", "pose": "sit", "at": [0.5, 0.6], "z": 42, "face": [0, 1],
  "need": { "energy": 0.2, "fun": 0.15 }, "dur": [8, 16], "label": "窝在沙发里", "layer": "front", "say": ["好软~"] }
```
- `pose`：stand walk sit sleep work read eat dance jump sad wave look
- `at`：落脚点（局部格坐标，可以在占地外面，比如书架前）；`z`：坐上去的高度；`face`：面朝方向
- `need`：用完能补多少需求（精力 energy / 乐趣 fun / 社交 social，0–1）——**角色会自己来用**
- `layer`：`front` 画在家具前（坐在沙发上）/ `back` 画在家具后（站在吧台后）
- `sets`：使用期间临时改家具状态（如电脑桌 `{ "working": true }` 让屏幕亮）

## 3. 场景 `roomkit.scene`

```jsonc
{
  "format": "roomkit.scene", "v": 1, "id": "cafe", "name": "鲸鱼咖啡馆",
  "room": {
    "w": 10, "h": 8,                                        // 1–40
    "cells": ["aaaaaaaaaa", "..."],                         // 可选：每格材质槽 a/b/c/d，"." = 空（L 形房、露天）
    "mats": [{ "kind": "wood", "color": "#e3a46a" }],       // wood tile carpet stone grass plain
    "walls": { "left": true, "right": true, "height": 300, "color": "#f6ead6", "wainscot": "#8fb0c9", "trim": "#ffffff", "pattern": "plain|stripes|dots" },
    "slab": 18
  },
  "objects": [
    { "id": "bar1", "def": "alice-cafe/counter", "x": 2, "y": 1, "rot": 0, "state": {}, "colors": { "main": "#c99" } },
    { "id": "win1", "def": "window", "wall": "right", "at": 4.5, "z": 100 }
  ],
  "agents": [
    { "id": "whale", "name": "大肥鱼", "brain": "pet", "character": "dafeiyu", "x": 5, "y": 4, "look": { "body": "#5b8def", "hat": "maid" } }
  ],
  "stories": [ /* 场景自带剧情：导出这个场景 = 分享一个可玩的小故事 */ ],
  "env": { "period": null, "weather": "clear" }
}
```
- 没有墙的大地面（`walls.left/right: false` + 草地/石板材质）就是露天广场；用 `cells` 挖空能拼出街道、院子。
- `brain`：`pet` 跟随 DSH 工作状态 · `auto` 自主生活 · `manual` 只听指令。

## 4. 剧情 `stories`

```jsonc
{
  "id": "fridge-secret", "name": "冰箱的秘密",
  "once": false, "daily": false, "marker": true,           // 只演一次 / 每天一次 / 头顶冒"！"
  "trigger": { "on": "click", "obj": "fridge1", "chance": 0.6 },
  "roles": { "fish": "whale", "pao": "paopao" },            // 剧本里的角色名 → 场景里的角色 id（也可 "pet" / "any"）
  "nodes": {
    "start": [
      { "do": "use",  "who": "pao", "obj": "fridge1", "slot": "eat", "s": 2.5 },
      { "do": "line", "who": "pao", "text": "（小声）就吃一口……", "expr": "happy" },
      { "do": "goto", "who": "fish", "to": "paopao", "run": true },
      { "do": "line", "who": "fish", "text": "泡泡！又偷吃！", "emote": "!" },
      { "do": "choice", "text": "你要……", "options": [
          { "label": "帮泡泡打掩护", "goto": "cover" },
          { "label": "一起审问", "goto": "catch", "if": "!flag:angry" } ] }
    ],
    "cover": [ { "do": "line", "who": "pao", "text": "是{{user}}让我拿的！" }, { "do": "inc", "flag": "snacks" } ],
    "catch": [ { "par": [ { "do": "pose", "who": "fish", "pose": "eat", "s": 3 }, { "do": "pose", "who": "pao", "pose": "eat", "s": 3 } ] } ]
  }
}
```

**触发**：`start`（进入场景）· `click`（点家具，`obj` 实例 id 或 `def` 家具类型）· `agent`（点某个角色）· `hour`（`from`–`to` 时段，可跨午夜）；`scene` 限定场景，`chance` 概率，`if` 条件。

**步骤**：

| 步骤 | 作用 |
|---|---|
| `line` | `who` 说一句（对话框 + 镜头推近），可带 `expr` 表情 / `emote` 头顶符号 / `pose` 动作 |
| `narrate` | 旁白 |
| `choice` | 选项分支：`options:[{ label, goto, if, set }]` |
| `goto` / `end` | 跳到节点 / 结束 |
| `set` / `inc` | 剧情变量（按场景存档）：`{ "do":"set", "flag":"metFish" }` |
| `goto`（带 obj/to/x,y）、`use`、`pose`、`emote`、`expr`、`face`、`outfit` | 角色走位、用家具、做动作、换表情、转身、换装 |
| `state` / `env` | 改家具状态（开灯）/ 改时段天气 |
| `par` | 并行：`{ "par": [步骤...] }`（多角色同时跳舞） |
| `wait` / `sfx` / `camera` | 等待 / 音效 / 镜头对准 |
| `cmd` | 剧终后排队一条命令（如让角色去睡觉），`id` 写 `"$角色名"` |

**条件 `if`**：`"flag:名"` `"!flag:名"` `"night"` `"day"` `"hour:22-2"` `{ "flag":"snacks", "gte": 3 }` 或数组（全部满足）。
**文本占位**：`{{user}}` = 玩家，`{{角色名}}` = 该角色的名字。

表情 `expr`：happy love surprised sad sleep · 头顶符号 `emote`：heart note ! ? spark idea anger sweat zzz think。

## 5. 角色卡 `roomkit.character`

```json
{
  "format": "roomkit.character", "v": 1, "id": "dafeiyu", "name": "大肥鱼", "kind": "whale",
  "look": { "body": "#5b8def", "belly": "#eef5ff", "hat": "maid" },
  "persona": "吃白饭的蓝色大肥鱼……",
  "phrases": { "greet": [], "idle": [], "night": [], "poke": [], "cheer": [], "oops": [], "wait": [] },
  "likes": { "fridge": 1.6, "bed": 1.2, "living": 1.1 },
  "schedule": [ { "from": 23, "to": 7, "prefer": "sleep" }, { "from": 12, "to": 13, "prefer": "eat" } ]
}
```
- `phrases`：不同场合的台词（气泡里显示，单句 ≤ 60 字）
- `likes`：对家具（id 或分类）的偏好倍数——喜欢的东西会更常去用
- `schedule`：作息——这个时段更想做哪种姿态的事（sleep/eat/work/read/sit/dance…）
- **SillyTavern / TavernAI 角色卡可以直接导入**（`chara_card_v2/v3` JSON、v1 JSON、带 `chara` 数据的 PNG）：开场白 → `greet`，示例对话里角色的台词 → `idle`，描述+性格 → `persona`（留给以后接模型对话）。
