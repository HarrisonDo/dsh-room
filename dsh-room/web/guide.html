创作指南

不用安装任何东西。下面的内容都在网页里完成，布置结果先保存在这个浏览器。

五分钟布置

  1. 点底部的「布置」。
  2. 从下方家具栏把一件家具拖进房间，放开即可。
  3. 选中家具后可以旋转、换颜色或删除。
  4. 点「家」回到游玩，刚才的改动已经自动保存。

连接房门

游玩时右键房门（手机上长按），在门旁的气泡里选择通往哪个房间。连接好以后，左键点门就会直接过去。

家具的占地和交互位

家具用 size 声明占几格，用 slots 声明角色站或坐的位置，at 以家具左上角为原点，单位是格。

{ "id": "stool", "name": "小凳子", "size": [1, 1], "height": 40,
  "art": { "kind": "proc", "parts": [{ "t": "cyl", "x": 0.5, "y": 0.5, "z": 0, "r": 0.3, "h": 40, "c": "#e3a46a" }] },
  "slots": [{ "id": "sit", "pose": "sit", "at": [0.5, 0.5], "z": 42, "face": [0, 1], "label": "坐一会儿" }] }

导入和导出

在「布置」的工具栏里可以导出当前房间，或导入内容包。清除浏览器数据会删掉本地房间，重要的布置请先导出。

让 AI 帮你改

把导出的房间 JSON 和上面的家具格式一起交给 AI，让它返回同样结构的 JSON，再用「导入」载入。导入时会校验格式，出错会指出具体字段。导入只影响你自己的本地房间，公开分享需要你另外操作。
