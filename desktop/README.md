# 大肥鱼的房间 · 桌面版

透明、无边框的窗口里只有房间和鲸鱼娘，可以放在桌面任何位置。目前提供源码运行方式；Windows 启动脚本已有，实际平台兼容性仍需实机验收。

普通用户请在 DSH 安装 `https://github.com/HarrisonDo/dsh-room`，打开房间后点击「放到桌面」。组件准备、同一份房间和模型接续由插件负责，无需单独安装本目录。见 [安装与桌面使用](../docs/17-安装与桌面使用.md)。

以下为源码桌面模式，用于开发；独立安装包属于后续 R06。Windows 桌面仍待实机验收。

## 从源码打开

- macOS：双击仓库根目录的 `打开桌面鲸鱼.command`
- Windows：双击仓库根目录的 `打开桌面鲸鱼.cmd`（需要先装 [Node.js](https://nodejs.org/)）
- 命令行：`cd desktop && npm install && npm start`

第一次打开会安装 Electron（约 100MB）。Electron 下载慢时，可以在安装前自行设置 `ELECTRON_MIRROR` 环境变量指向你信任的镜像。

## 操作

| 操作 | 效果 |
|---|---|
| 点角色、家具、地板 | 和网页版一样：互动、走过去 |
| 在房间上拖动 | 移动窗口 |
| 滚轮 | 放大 / 缩小 |
| 左键房门 / 右键房门 | 直接换房 / 打开门旁交互气泡 |
| 其他位置右键（或鼠标碰到房间后，顶部出现的 ⋯） | 换房间、时间、天气、大小、总在最前、在所有桌面显示（macOS）、打开完整房间、退出 |
| 房间之外的透明处 | 点击穿透到下面的桌面和窗口 |

「打开完整房间」会打开带顶栏和菜单的普通窗口，可以布置、聊天、看地图。关掉它，桌面上的房间就会回来，布置的结果也跟着回来。

## 实现

- `main.js`：主进程。透明窗口默认忽略鼠标，同时把鼠标移动转发给页面。页面判断鼠标下面有没有东西，再通知主进程接不接点击（`setIgnoreMouseEvents(…, { forward: true })`）。
- `preload.cjs`：只给页面暴露几项窗口操作（`window.roomkitDesk`），页面拿不到 Node。
- 页面直接读 `../dsh-room/web`，走自定义协议 `app://roomkit/`，**不监听任何网络端口**。引擎的桌面模式见 `dsh-room/web/roomkit/desk.js`（`?desk=1`）。
- 窗口位置、大小、是否置顶存在系统的用户数据目录里的 `desk.json`（macOS：`~/Library/Application Support/大肥鱼的房间/`）。

## 存档

通过 DSH「放到桌面」启动时，宿主保存完整本地快照，桌面小窗、完整窗、DSH 内嵌房间轮流接管，避免双写。它包含房间、门连接、角色与自定义素材。凭据仍留在 DSH。

通过本目录 `npm start` 启动的独立源码模式使用 Electron 自己的存档，与 DSH 和浏览器预览分开；本端小窗和完整窗共用存档。

Web、独立 App 和其他设备之间的账户云同步后置，具体设计见 [三端同步方案](../docs/14-三端账号与数据同步方案.md)，当前界面范围见 [UI 改造交接](../docs/13-Web入口与三端UI改造交接.md)。
